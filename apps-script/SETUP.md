# Як підключити форму заявок (Google Apps Script + Google Sheets)

Займе близько 10 хвилин. Усе безкоштовно і працює у вашому Google-акаунті.

## 1. Створіть таблицю
1. Відкрийте https://sheets.new — створиться нова Google-таблиця.
2. Назвіть її, наприклад, «Warm Hands — заявки».

## 2. Вставте код
1. У таблиці: **Розширення → Apps Script**.
2. Видаліть усе у файлі `Code.gs` і вставте вміст файлу [`Code.gs`](Code.gs) з цієї папки.
3. Натисніть 💾 (Зберегти).

## 3. Опублікуйте як веб-застосунок
1. Справа вгорі: **Розгорнути (Deploy) → Нове розгортання (New deployment)**.
2. Тип (шестерня): **Веб-застосунок (Web app)**.
3. Налаштування:
   - **Виконувати від імені (Execute as):** Я (ваш акаунт)
   - **Хто має доступ (Who has access):** Усі (Anyone)
4. Натисніть **Розгорнути**. Google попросить дозволи (таблиця + надсилання листів) —
   натисніть «Дозволити». Якщо з'явиться «Google не перевірив цей застосунок»:
   **Додатково → Перейти до проєкту (небезпечно)** — це ваш власний скрипт.
5. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`).

## 4. Надішліть URL Claude
Claude вставить його у `config.js` (поле `API_URL`) і оновить сайт.
Після цього запрацюють форма, лист-підтвердження і лічильник.

## Що де лежить
- Лист **Signups** — усі заявки. Колонка `confirmed` = TRUE лише після кліку в листі.
- Лічильник на сайті показує тільки підтверджені заявки (оновлюється раз на хвилину).
- Меню **Warm Hands → Refresh referral stats** створює лист **Referrals**:
  скільки заявок прийшло через кожне особисте посилання.

## Обмеження
- Звичайний Gmail може надсилати ~100 листів на добу. Для 150–300 заявок за 6 тижнів цього достатньо.
- Листи надходитимуть з вашої адреси Gmail.
- Якщо змінюєте код — **Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова**,
  щоб URL лишився тим самим.
