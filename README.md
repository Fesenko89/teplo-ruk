# Тепло рук — сайт благодійного фонду

Односторінковий сайт благодійного фонду «Тепло рук» (ендавмент для підтримки людей пенсійного віку) трьома мовами: українською, англійською та іспанською.

## Структура

- `index.html` — сторінка; український текст написаний прямо тут.
- `i18n.js` — англійські (`en`) та іспанські (`es`) переклади, ключі збігаються з атрибутами `data-i18n`.
- `app.js` — перемикач мов (запам'ятовує вибір, підтримує `?lang=en`/`?lang=es`) і мобільне меню.
- `styles.css` — стилі.

## Як змінити текст

1. Українською — відредагуйте текст у `index.html`.
2. Англійською/іспанською — знайдіть той самий ключ у `i18n.js`.

## Публікація

Сайт розміщено на GitHub Pages (гілка `main`, корінь репозиторію).
