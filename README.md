# Warm Hands (Тепло рук) — One Dollar. Forever.

Сайт етапу 0: перевірка попиту на ендавмент для українських пенсіонерів.
Англійською, одна сторінка. Гроші не приймаються — лише заявки про намір.

## Файли

- `index.html` — сторінка: hero, механізм, калькулятор, хто за цим стоїть, статус, форма.
- `privacy.html` — Privacy Policy (GDPR).
- `config.js` — **налаштування**: URL бекенду форми, email, Reddit, припущення калькулятора за замовчуванням.
- `app.js` — калькулятор, форма, лічильник, реферальні посилання.
- `styles.css` — стилі.
- `mykola.jpg` — фото засновника (якщо файлу немає, показуються ініціали).
- `apps-script/` — бекенд форми для Google Apps Script і інструкція [`SETUP.md`](apps-script/SETUP.md).

## Формула калькулятора

```
w = r − 0.01 − 0.005
P = 12 × payout_uah / fx
C = P × (1 + 1.25 × w) / w / (0.90 × 0.965)
```
r=5% → C ≈ $9 160; r=3% → ≈ $20 850; r=6% → ≈ $7 210.
